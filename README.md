# Dock Switcher

Небольшое приложение для строки меню macOS. Оно автоматически меняет настройку скрытия Dock в зависимости от активных экранов.

- Только встроенный экран MacBook — Dock скрывается и появляется при наведении на край экрана.
- Есть активный внешний монитор — Dock остаётся видимым. Это работает и с закрытой крышкой MacBook.

При смене режима Dock кратко перезапускается. Проверка экранов происходит при запуске, после выхода из сна и при изменении конфигурации дисплеев. Повторную проверку можно запустить через меню приложения.

## Установка

Скачай [DockSwitcher.zip](./DockSwitcher.zip), распакуй и перенеси **Dock Switcher.app** в папку **Программы**. Готовая сборка рассчитана на Apple Silicon и macOS 13 или новее. Она подписана локально и не нотарифицирована Apple.

Для автозапуска добавь приложение в **Системные настройки → Основные → Объекты входа и расширения → Открывать при входе**.

## Сборка из исходников

Понадобятся macOS 13 или новее и Xcode Command Line Tools.

```sh
xcode-select --install  # если инструменты ещё не установлены
bash build.sh
```

Скрипт соберёт приложение для архитектуры текущего Mac, проверит логику выбора режима и создаст `build/DockSwitcher.zip`.
